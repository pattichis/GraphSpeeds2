# Lecciones de ESTRELLA de 7.º grado para explorar relaciones lineales con Python y videos digitales
Las lecciones de abajo apoyan los siguientes estándares: CCSS.Math.Content.7.RP.A.2.A, 7.RP.A.2.B y 7.RP.A.2.A.C.

El repositorio incluye materiales interactivos para explorar gráficas, rapideces, distancias, tablas y relaciones lineales en Python.

El código permite que los estudiantes de 7.º grado visualicen relaciones por medio de tablas, imágenes y animaciones en video. Los estudiantes crean historias en video digital para explicar distintas relaciones. 

El salón necesita acceso a Google Drive para guardar los proyectos de los estudiantes. Con acceso a internet, los estudiantes pueden usar todo el material en su navegador sin necesidad de apoyo adicional.

Al usar Google Colab, también contamos con una interfaz dedicada para que Gemini conteste preguntas sobre el código. La interfaz se puede usar para explicar mejor partes del código y para quitar las barreras que presenta tener que entender código en Python.
